### 수정 이력 (이번 단계에서 캡처 → 고침 반복)
1. 보통 품질 화면이 통째로 검게 나옴 → 바닥 창빛 판과 빗줄기에 법선이 없어 AO 법선 패스에서 NaN이 생겼고, Bloom이 이를 화면 전체로 번지게 함. 법선 추가로 해결.
2. 평대·계산대 판재가 검게 나옴 → 판재 밝기 값을 색 hex로 넘긴 버그. 수정.
3. 1차 구도에서 빈 바닥 비중이 크고 오른쪽 서가가 잘림 → 카메라를 오른쪽 앞 모서리로 옮김. 창가 벤치와 소파 앞 낮은 테이블 추가.
4. 스탠드 주변이 하얗게 날아감 → 스탠드 광량·갓 발광을 낮추고 Bloom 임계값을 올림.
5. 창밖 건물이 창 전체를 막아 하늘이 안 보임 → 건물 높이를 창 시야에 맞추고, 가까울수록 진하게 조정.
6. 징두리·서가 뒤판 틈으로 흰 벽이 비침 → 어두운 받침판 추가.
7. 보통 품질에서 가구 밑 그림자가 약함 → 접지 그림자 판(드로우콜 1개) 추가.
8. 책이 736권으로 목표(400~700) 초과 → 칸별 빈틈 비율 상향.

### 수정 이력
1. 읽기 모드에서 얼굴 한가운데 세로 줄 → 아바타를 AO에서 뺐더니 뒤 소파 쿠션 틈의 AO가 얼굴에 찍힘. 아바타는 AO에 다시 넣고, 이름표·아이콘·발밑 그림자만 오버레이 레이어로 분리.
2. 읽기 모드 카메라가 머리 뒤에 붙어 화면이 머리로 가려짐 → 어깨 너머 구도를 시도했으나 머리 큰 아바타라 책이 가려져, 앞쪽 비스듬한 위에서 책 읽는 내 아바타를 보는 구도로 변경.
3. 시작 위치가 앞벽에 가까워 카메라가 아바타에 붙음 → 시작 자리와 카메라 기본 각도(27°, 3.3m) 조정, 세로 화면은 더 위를 보게.
4. 이름표가 멀리서 너무 작음 → 거리 비례 크기(0.8~2.6배)로 키움.
